# Hi, I'm Gluek 👋

**Do whatever you want with my code, just don't make it boring.**

I build self-hosted tooling around **Delta Chat / chatmail**, censorship circumvention and decentralized networks (Yggdrasil, I2P, Reticulum).

## 🤖 Delta Chat bots

| Project | Description |
|---|---|
| [deltachat_telegram_bridge](https://github.com/mrgluek/deltachat_telegram_bridge) | Bridge between Delta Chat groups and Telegram groups, relaying messages both ways |
| [deltachat_yt](https://github.com/mrgluek/deltachat_yt) | Downloads YouTube video and audio via yt-dlp, within the 50 MB email limit |
| [deltachat_webpreview](https://github.com/mrgluek/deltachat_webpreview) | Saves web pages as single self-contained HTML files and sends them back |
| [deltachat_uptime](https://github.com/mrgluek/deltachat_uptime) | Self-hosted uptime monitoring (HTTP, TCP, Ping) with per-chat isolation and status pages |
| [deltachat_bouncer](https://github.com/mrgluek/deltachat_bouncer) | Group activity monitoring, catalogs, welcome messages, relay connectivity checks |
| [deltachat_username](https://github.com/mrgluek/deltachat_username) | Short invite link service and custom usernames |
| [deltachat_publish](https://github.com/mrgluek/deltachat_publish) | Publish posts and images from Delta Chat to Astro blogs (IndieWeb / POSSE) via Forgejo |
| [deltachat_ntfy](https://github.com/mrgluek/deltachat_ntfy) | ntfy.sh-compatible backend that delivers HTTP POST notifications to Delta Chat |
| [hass-addons-deltachat](https://github.com/mrgluek/hass-addons-deltachat) | Home Assistant add-ons for the Delta Chat bots |
